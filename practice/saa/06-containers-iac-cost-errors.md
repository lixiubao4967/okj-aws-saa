## 📌 两层角色按时间先后记

```
Task Execution Role = 【启动容器之前】ECS 代理需要的权限（拉 ECR 镜像、建日志流）
Task Role           = 【容器跑起来之后】你的代码需要的权限（读 S3、写 DynamoDB）
```

> Execution 在前（准备阶段），Task 在后（运行阶段）。
> 题干说「**容器内的应用**要访问 XX」→ 一定是 **Task Role**。

## 📌 ECS vs EKS 的分界线不是规模

「大规模必须用 EKS」是流传很广的误解。ECS 支撑着极大规模的生产负载。
**分界线只有一个：Kubernetes 生态（kubectl / Helm / 多云 / 现有 K8s 迁移）。**

## 📌 Fargate vs EC2 模式：只有三个信号选 EC2

1. 需要 **GPU**
2. 需要**特定实例类型**（如超大内存）
3. 要用 **Spot** 大幅降本

**看不到这三个，就选 Fargate。**
